# 截图助手使用说明

版本：1.2.3。适用于 Windows 10/11 x64，运行主程序需要 .NET Framework 4.8。

## 解压与启动

1. 将绿色版压缩包完整解压到一个可写文件夹。
2. 保留 `截图助手.exe` 旁的 `RecorderNative.dll` 与完整 `ocr` 文件夹，然后双击主程序。
3. 程序常驻任务栏托盘。双击托盘图标开始截图；右键可打开设置、开始录制或退出。

本地 OCR 引擎和模型约占 32 MiB。绿色版无需安装，但包含主程序和 `ocr` 目录；只复制主程序会使本地识别不可用。移动到其他电脑时请复制整个文件夹。

默认截图热键为 `Alt+A`。若被其他软件占用，程序会尝试其他组合；请以托盘提示中的当前热键为准。录制热键默认为 `Ctrl+Shift+P`，均可在设置中修改。

## 首次设置

右键托盘 →「设置…」。设置分为三个标签页：

| 标签页 | 用途 |
| --- | --- |
| 本地识别 | 检查 OCR 组件、选择智能打码的联网语义补漏和头像/二维码检测 |
| API 与翻译 | 填写 API Key、Base URL、模型和目标语言，测试文本接口 |
| 截图与录制 | 设置热键、保存目录、复制/保存行为、开机自启与录制参数 |

不填 Key 即可使用截图、标注、本地文字提取和本地隐私规则检测。翻译需要可用的文本 API。

接口地址和模型需要与所填服务一致。设置页会显示当前默认值；已有配置中的自定义接口及显式路径会保留。“恢复默认”会恢复内置接口配置，并避免把不匹配的凭据自动带到另一服务。

绿色版不包含实际 API Key，请在设置中填写。Key 使用 Windows DPAPI 加密保存，绑定当前 Windows 用户；换电脑或换用户后需重新填写。配置优先保存为主程序旁的 `config.json`；目录不可写时转存到 `%APPDATA%\截图助手\config.json`。

开机自启默认关闭。在「截图与录制」或托盘菜单中开启后，程序使用当前用户的启动项；移动程序文件夹后需要重新设置。

## 截图与编辑

按截图热键，按住左键拖拽框选。拖动时可查看选区边框和尺寸；确定后在工具栏选择矩形、椭圆、箭头、画笔、文字、序号等工具。

- 文字：点击位置后输入，`Enter` 确认，`Esc` 取消；已提交文字可拖动，双击可再次编辑。
- 打码：选择马赛克工具后涂抹。当前遮挡使用不透明图案，不从原图取像素生成图案。
- 按 `V` 或点击选择工具，选中标注后拖动位置、拖动边框控制点缩放；`Delete` 删除，`Esc` 取消当前拖动/选择。
- 撤销：`Ctrl+Z`；重做：`Ctrl+Y` 或 `Ctrl+Shift+Z`；保存：`Ctrl+S`；完成复制：`Enter` 或 `Ctrl+C`。
- 钉图：点击图钉按钮。使用右上角关闭按钮、`Esc` 或右键菜单关闭钉图。
- 导入：可从托盘选择图片、将图片拖入编辑器，或在画布按 `Ctrl+V` 粘贴剪贴板图片。
- 拼图：托盘「拼图工具」支持多图排序、横排或纵排、间距和背景设置。
- 延时与复用：托盘提供 3/5/10 秒延时截图和上次选区复用。

标注与译文只改变输出截图，不修改屏幕中的原应用内容。

界面采用冷白浮层、深灰线稿图标、柔和圆角和单一系统蓝强调色。选区使用白色外轨、系统蓝内轨与圆形控制点；文字输入栏保持清晰深色文字，画面预览及导出继续使用你选择的标注颜色。

## 本地文字提取

框选文字 → 点击「文字提取」→ 在结果面板查看或复制文字。

使用本地离线识别运行时，不需要 Key，不上传截图。识别同时返回文字和原图中的位置；超长图片会分片识别，避免整体缩小后丢失小字。

组件缺失时会提示检查 `ocr` 文件夹，不会自动改为上传截图识别。识别后会结合同行正文、图形结构和置信度过滤重复的侧边图标；不会按短字符或英文统一删除。默认不逐行翻转方向，倒置文字需先转正。OCR 仍可能漏字、错字或合并英文空格；手写字、艺术字与低清晰度图片的结果需核对。

## 原位翻译

先在「API 与翻译」设置目标语言，框选文字后点击「文字翻译」。程序在本地识别文字与位置，再将识别文字发给文本 API 翻译；此流程不上传截图。

译文覆盖在对应原文框内，并按可用空间调整字号和换行。完整译文保存在标注对象中。按 `V` 选择译文块，可移动或扩框；双击、`F2` 或右键可修改译文，`Ctrl+Enter` 应用，`Esc` 取消输入。`Ctrl+Alt+T` 切换当前译文对象的原文/译文。删除只移除当前块。移动后仍遮盖原文字位置；这些操作均可撤销/重做。

纯色背景效果通常较清楚；复杂图片背景、装饰字体与特殊排版可能无法自然还原。接口返回行缺失或格式错误时会报告问题，不按返回顺序把译文配到其他行。

## 智能打码

在马赛克按钮上右键 →「智能打码（本地文字检测，可配置联网补漏）」。本地规则结果先出现在编辑器中，联网补漏在后台继续，编辑器左上角会显示阶段状态。本地完成后即可编辑、复制或保存；继续编辑会取消尚未完成的补漏，避免迟到结果改变新画面。按 `Esc` 可取消当前检测并保留已应用遮挡；同一轮本地与联网遮挡可用一次 `Ctrl+Z` 撤销。

| 检测方式 | 默认状态 | 数据去向与能力 |
| --- | --- | --- |
| 本地 OCR + 规则 | 可直接使用 | 在本机检测手机号、证件/银行卡类长数字、邮箱、验证码、密钥及带标签的姓名、账号、地址等；支持分组数字和全角数字 |
| 联网语义补漏 | 开启，有 Key 时使用 | 本地结果显示后，仅发送尚未命中本地规则的文字，补充姓名、住址等语义判断；无 Key 时仍可做本地检测 |
| 检测头像与二维码 | 关闭 | 开启后上传选区截图，已确定的敏感文字先遮挡；需显式配置支持图片的模型，检测仍可能遗漏 |

默认配置不会检测头像和二维码。若需要完全离线打码，请在「本地识别」关闭「联网语义补漏」，并保持「检测头像与二维码」关闭。后台联网阶段最多等待 20 秒，或使用设置中更短的超时；超时、取消或失败不会移除已应用的本地遮挡。

自动识别可能漏判或误判。输出前检查文字、头像及二维码等区域，遗漏处可手动涂抹。自动命中区域使用不透明遮挡；它不会保留该区域原图的马赛克均值。

检测时会打开「智能打码审阅」。默认遮挡全部候选，可关闭某一类别或取消单处误判；点击列表项定位画面中的候选，点击「补选区域」后用马赛克补充。更改审阅会停止本轮后台补漏，避免迟到结果重新加回取消项。点击「完成审阅」保留当前勾选结果；审阅修改可用 `Ctrl+Z` 撤销。类别按整条 OCR 识别行归属，含多类信息的同一行不会拆成独立字段。

## 长截图与录制

长截图：框选可滚动内容区域 → 点击「长截图」→ 滚动原窗口。预览窗显示当前结果与捕获段，点击段可检查接缝；点击预览可查看原始像素。发现问题可暂停、撤回末段，再滚回原窗口重试；可恢复撤回的末段。`Enter` 完成，`Esc` 取消。无滚动信号时暂停抓帧，错位帧被拒绝后也会暂停。原帧撤回历史限 128 MiB，达到限制会提示完成；长图重建可能耗时。固定浮层、动画、惯性滚动仍可能影响拼接，不支持混合方向滚动。

录制：从托盘或 `Ctrl+Shift+P` 框选区域，弹出「录制准备」。确认选区后选择不录声音、系统声音、麦克风或两者混合，再点击「开始录制」。开始前不会创建录制文件或打开音频设备；「重新选择」、关闭准备窗口或按 `Esc` 返回框选。准备窗可拖动，本次选择不改写设置中的默认值。

新配置默认 MP4/H.264、不录音频；已有配置保留原 AVI 选择。MP4 使用默认系统音频设备，设备不可用时会报告错误。AVI 仅支持画面，选择音频时准备窗会切换为 MP4 并提示。

点击「暂停/继续」或按 `F8`，暂停时间不会计入视频，也不抓帧；按 `Esc` 或「停止」保存。控制条约 360×44 DIP，只显示计时及暂停/停止按钮，悬停查看帧数、体积及文件名。支持系统捕获排除时，控制条持续可见但不进入视频，计时区域局部刷新；旧系统无法排除且无选区外空间时使用键盘控制。奇数 MP4 选区会补齐右/下 1 像素以满足编码尺寸要求。抓帧卡顿会重复上一帧，因此可能短暂静止。AVI 接近约 4 GiB 会安全停止；MP4 依赖系统媒体组件，Windows N 版本等缺失媒体功能的系统可能无法编码。长时间录制、实际磁盘写满、真实麦克风语音及混合录音尚未实机验收。

## 独立快捷操作

| 操作 | 默认快捷键 | 命令行 |
| --- | --- | --- |
| 本地提取文字 | `Alt+Shift+O` | `--ocr` |
| 翻译选区 | `Alt+Shift+T` | `--translate` |
| 智能打码 | `Alt+Shift+M` | `--redact` |

按热键后框选即执行；已在编辑器内时使用当前选区。快捷键可在设置中分别修改，按 `Delete` 清空可禁用。冲突时会提示，仍可从托盘启动。命令行会转交给正在运行的同版本实例。升级前请先退出旧版本，再完整解压新版本。

## 联网范围与常见问题

- 文字提取和本地规则检测在本机完成。
- 翻译、已启用且配置了 Key 的语义补漏，会发送选区识别出的文字到你填写的 API 地址。
- 只有显式开启头像/二维码检测时，该流程才上传选区截图；不要把文本模型默认视为视觉模型。
- 本次开发没有有效的用户完整 Key，未验证真实外网服务；文本接口使用本地 mock 验证，OCR 使用真实本地引擎验证。
- 「组件缺失」：重新完整解压，确认 `ocr` 目录、其中的可执行文件和 `models` 均保留。
- 接口失败：核对 Key、服务要求的地址、模型权限及网络，再执行「测试连接」。
- 退出：右键托盘 →「退出」。退出后可移走程序文件夹；若开启过自启，先在设置中关闭。
