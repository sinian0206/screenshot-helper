# 微信截图助手（DeepSeek 版）使用说明

> 版本 1.0.0 · 绿色免安装 · 适用于 Windows 10 / 11
>
> 一个用起来像微信截图（Alt+A）的 Windows 截图工具：框选、标注、打码、保存、钉图、长截图一应俱全，
> 还能用 DeepSeek AI 一键「提取文字」「翻译截图」「智能打码」。单个 exe，解压即用。

---

## 一、这个工具能做什么

- **熟悉的截图体验**：按 `Alt+A`，屏幕定格，拖拽框选或单击智能选中窗口，然后像微信截图一样画矩形、椭圆、箭头、画笔、贴表情、写文字、打马赛克。
- **AI 加持**（需要 DeepSeek API Key）：
  - 文字提取：把截图里的文字识别成可复制的文本；
  - 文字翻译：截图里的外文先识别、再翻译成中文（目标语言可改）；
  - 一键智能打码：AI 自动识别头像、姓名、手机号、证件号等隐私区域并打码。
- **长截图**：滚动页面自动拼接成一张完整长图。
- **钉在桌面**：把截好的图钉在屏幕最上层，对照资料、看步骤图非常方便。
- **点击转发**：复制图片并自动切到微信，直接 `Ctrl+V` 发给好友。
- **绿色便携**：只有一个 exe，不写注册表安装项、不需要额外 DLL；配置和 API Key 都留在本机。
- **中文界面**：所有按钮、提示、报错都是中文，适合普通用户。

## 二、系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10（1903 及以上版本）、Windows 11 |
| 运行环境 | 系统自带 .NET Framework 4.8，**无需另外安装**（Windows 11 和近年的 Windows 10 都已自带） |

> 如果你的 Windows 10 比较老、提示缺少 .NET Framework 4.8，请先通过 Windows 更新安装，或到微软官网下载安装包。

## 三、绿色版使用（解压即用）

1. 把收到的 `微信截图助手_v1.0.0_绿色版.zip` **解压**到一个文件夹，例如 `D:\Tools\微信截图助手\`。
   - 不要在压缩包预览窗口里直接双击运行，请先「全部解压」。
   - 建议不要放在 `C:\Program Files` 这类受保护目录：本工具会把配置保存在 exe 同目录，放受保护目录时会自动改存到 `%APPDATA%\微信截图助手\`。
2. 双击文件夹里的 **`微信截图助手.exe`**。
3. 程序不会弹出主窗口，而是常驻在屏幕右下角的**托盘区**（一个绿色小图标）。
4. 按 `Alt+A` 就可以开始截图（热键可在设置里修改）。也可以**双击托盘图标**，或在托盘图标上右键选择「截图」来开始。
5. 想退出程序：在托盘图标上点**右键 → 退出**。
6. 程序是**单实例**的：重复双击不会启动第二个，只会提示「微信截图助手已在运行，按 Alt+A 开始截图」。
7. **首次运行**会自动弹出标题为「欢迎使用微信截图助手」的引导窗口，引导填写 API Key、设置热键和保存目录；如果暂时不想配置，可以点「取消」跳过（基础截图功能不受影响），之后在托盘菜单「设置…」里补填即可，下次启动还会再次引导。

> 小提示：第一次运行建议先按下面「四、首次配置」填写 API Key；不填也能正常截图、编辑、保存，只是 AI 功能会提示需要配置。

## 四、首次配置（获取并填写 DeepSeek API Key）

1. **打开设置**：在托盘图标上右键 →「设置…」（首次启动时会自动弹出欢迎/设置窗口）。
2. **获取 API Key**：
   1. 用浏览器打开 <https://platform.deepseek.com>，注册并登录（也可以在设置窗口里点「获取 API Key」按钮直接打开该页面）；
   2. 进入「API Keys」页面，点击「创建 API Key」；
   3. 复制创建好的 Key（通常是 `sk-` 开头的一长串字符，**只显示一次**，请妥善保存）。
3. **填写并保存**：回到本工具设置窗口的「AI 设置」区域，把 Key 粘贴到「API Key」输入框（可点「显示」核对是否完整），点击「测试连接」，看到「连接成功，耗时 x 秒」即表示可用，再点「确定」保存。
   - 如果暂时不想填 Key 就点确定，程序会提示「暂不填写 API Key 也可以使用基础截图功能……仍然保存吗？」，选择「是」即可先使用基础功能。
4. **API Key 会加密保存**：程序使用 Windows 自带的 DPAPI 加密（绑定当前 Windows 用户），保存在 exe 同目录的 `config.json` 里，**不会明文保存**。换一台电脑或换一个 Windows 用户后无法解密，需要重新填写（设置窗口会提示「API Key 无法解密……请重新填写」）。
5. **不填 Key 也可以用**：普通截图、标注、保存、钉图、长截图都不需要 Key；点 AI 功能（文字提取/翻译/一键打码）时会弹出提示，点「是」可直接打开设置窗口填写，也可以先继续用基础功能。

> 如果你的网络需要代理，或使用兼容 DeepSeek 接口的第三方服务，可以在设置的「Base URL」里修改接口地址（默认 `https://api.deepseek.com`）。不确定时不要改。

## 五、开始截图

按 **`Alt+A`** 进入截图模式（也可以双击托盘图标，或在托盘右键菜单点「截图」）：

> **热键被占用怎么办？** 微信截图默认也是 `Alt+A`，如果这个热键已被微信/QQ 等程序占用，本工具启动时会自动尝试改用
> `Alt+Shift+A`、`Ctrl+Alt+A`、`Alt+Shift+S`、`Ctrl+Alt+S` 中第一个可用的组合，弹出提示并把新热键写进配置
>（托盘菜单和托盘图标悬停提示都会显示当前热键），也可以在设置里随时修改。如果这些组合都被占用，会提示
> 「全局热键 xxx 注册失败（可能被其他软件占用），请到设置中更换」。
> 如果设置窗口正开着，截图请求会被忽略并提示「请先关闭设置窗口再截图」，关掉设置窗口再按热键即可。

1. **屏幕定格**：整个屏幕会变暗，并出现十字光标。
2. **框选区域**：
   - 按住鼠标左键拖拽，框出需要的区域；
   - 也可以**直接单击**某个窗口：鼠标悬停时会高亮窗口并显示窗口标题，单击即可选中整个窗口（智能窗口识别）。
3. **调整选区**：
   - 选区四周有 8 个绿色手柄，拖动手柄可调整大小；
   - 在选区内部按住拖动，可整体移动选区位置；
   - 方向键可微调选区位置（按住 `Shift` 加速）。
4. **看尺寸和颜色**：选区左上角会显示当前选区的「宽 × 高」像素尺寸；鼠标旁会显示鼠标所在位置的颜色值（如 `#07C160`）。
5. **复制色值**：按 `C` 可复制当前鼠标位置的颜色值到剪贴板。
6. **取消**：按 `Esc` 或鼠标右键，放弃本次截图。

> 选区确定后，工具栏会自动出现在选区下方（如果下方空间不够，会出现在上方）。

**快捷完成**：在不选用任何标注工具时，在选区内**双击鼠标左键**可以直接完成截图（等同于点「完成」）。

## 八、标注技巧

- **撤销 / 重做**：画错了按 `Ctrl+Z` 撤销，撤销多了按 `Ctrl+Y` 恢复。
- **颜色和线宽**：在工具按钮上点右键即可修改，修改后继续画即可生效。
- **文字**：点「文字」后在截图上点一下出现输入框，输入时可用 `Ctrl+滚轮` 调字号；按 `Enter` 确认，按 `Esc` 取消。点击输入框以外的地方也会确认文字。
- **序号**：点「序号」按钮（或按 `N`）后连续点击，序号自动递增；右键序号按钮可「重新开始编号」。
- **马赛克**：选「马赛克」后按住左键涂抹要遮挡的区域；笔刷大小可右键调整；涂错了用 `Ctrl+Z` 撤销。
- **清空重画**：`Ctrl+A` 一次清空所有标注。
- **选区锁定**：一旦开始添加标注，选区位置和大小会锁定，避免手滑移动；撤销掉所有标注后可继续调整选区。
- 所有标注都只影响「这次截图」，不会修改原屏幕内容。

## 九、AI 文字提取（OCR）使用说明

1. 框选要识别的文字区域（尽量把文字框完整，边缘不要贴太紧）。
2. 点击工具栏的「**文字提取**」。
   > 如果还没有配置 API Key，会弹出提示，点「是」即可直接打开设置窗口填写（详细步骤见第四节）。
3. 编辑器旁边（优先右侧，空间不够时在左侧或居中）会出现标题为「**文字提取**」的结果面板，识别结果会**边识别边显示**（流式输出），识别中显示「正在识别…」。
4. 识别完成后：
   - 可以直接在文本框里选中复制；
   - 或者点面板上的「**复制全部**」按钮一键复制全部文字；
   - 面板底部会显示本次调用的 token 用量和耗时（可在设置里关闭「显示 token 用量」）；
   - 点右上角「关闭」按钮关掉面板，回到截图继续编辑。
5. 如果识别失败，面板会显示中文错误提示和「**重试**」按钮；点重试可重新发起识别。

> 提示：文字提取只把**你框选的那张截图**发送给 DeepSeek，不会上传整个屏幕。截图越清晰、文字越正，识别越准确。

## 十、AI 文字翻译使用说明

1. 框选需要翻译的外文区域。
2. 点击工具栏的「**文字翻译**」。
   > 如果还没有配置 API Key，会弹出提示，点「是」即可直接打开设置窗口填写（详细步骤见第四节）。
3. 程序会先识别图中文字，再翻译成设置里的「目标语言」（默认中文）。面板标题为「**文字翻译**」，翻译中显示「正在翻译…」。
4. 结果面板上方是「**原文**」、下方是「**译文**」，两者都会流式显示；
   - 可以分别复制原文 / 译文，也可以点「**复制全部**」一次性复制；
   - 面板底部显示 token 用量和耗时（可在设置中关闭）；
   - 点关闭按钮回到截图继续编辑；失败时可点「重试」。
5. 想换目标语言：打开「设置」→「翻译目标语言」下拉框选择（中文 / English / 日本語 / 한국어 / 自动，也可直接输入自定义语言），确定后生效。

> 翻译同样只发送框选区域。AI 结果仅供参考，重要内容请人工核对。

## 十一、一键智能打码

1. 先框选截图区域。
2. **在「马赛克」工具按钮上点鼠标右键** → 选择「**一键智能打码**」。
3. 程序会把选区截图交给 DeepSeek 视觉模型，自动找出头像、姓名、手机号、证件号等隐私区域，并自动加上马赛克。
4. 完成后会提示「已对 N 处隐私信息打码」：
   - 可以继续用马赛克工具手动补涂；
   - 打错了按 `Ctrl+Z` 撤销整块智能打码结果；
   - 如果没识别到，会提示「未识别到需要打码的隐私信息」。
5. 打码效果确认无误后，点「完成」或「转发」等按钮输出。

> 注意：AI 识别不能保证 100% 覆盖所有隐私信息，**请务必在发送前自己再检查一遍**。

## 十二、长截图使用说明

1. 框选需要滚动截取的区域（比如聊天记录、网页、文档列表）。
2. 点击工具栏的「**长截图**」。
3. 截图编辑器会暂时隐藏，选区出现**绿色边框**和一个**控制条**：控制条上有拼接进度/预览，以及「**完成 (Enter)**」「**取消 (Esc)**」按钮；同时提示「滚轮 / PageDown 滚动目标窗口，自动拼接」「Enter 完成，Esc 取消」。
4. 把鼠标放在选区内，用以下方式滚动目标窗口的内容，程序会自动抓取并拼接每一段画面：
   - **鼠标滚轮**（竖向/横向滚轮都可以）；
   - `PageDown` / `PageUp` / 空格 / `Home` / `End` / 方向键（这些按键在滚动目标窗口的同时会触发抓帧）；
   - 拖动目标窗口自己的滚动条或使用中键滚动也可以（程序会定时兜底抓帧）。
5. 拼接过程中可以随时结束：
   - 点「**完成 (Enter)**」或按 `Enter`：生成一张完整长图，并弹出结果窗口；
   - 点「**取消 (Esc)**」、按 `Esc` 或在选区内点鼠标右键：放弃本次长截图，返回截图编辑器；
   - 达到拼接上限时会自动结束并生成已有结果；
   - 如果始终没有检测到内容滚动，程序会提示「未检测到滚动，已返回当前选区画面」，把当前选区画面作为结果返回。
6. 长截图完成后会打开**长截图结果窗口**（标题显示「长截图结果 宽 × 高」）：
   - 窗口可以拖动、调整大小，图片会自适应预览；
   - 顶部按钮：**复制图片** / **保存…** / **钉在桌面** / **关闭**；
   - 保存默认文件名是 `长截图_日期_时间.png`（或 .jpg），默认目录同样是 `图片\微信截图助手\`；
   - 按 `Esc` 也可关闭结果窗口。

> 提示：长截图期间尽量不要让页面出现弹窗、动画或遮挡；滚动速度放慢一点，拼接会更准确。

**使用限制与建议（重要）**

- **放慢滚动**：每滚一小段（大约半个选区高度）停一下，等画面稳定再继续，拼接最准确；
- **滚动过快**：程序可能抓不到重叠区域，此时会忽略该帧继续尝试，结果可能缺少中间内容，建议放慢重试；
- **重复/纯色内容**：空白文档、大片纯色或高度重复的页面难以判断相邻帧的重叠位置，建议缩小选区、分段多次截取；
- **动画、视频、弹窗、悬浮广告**：容易造成错位或内容重复，截图时尽量先关掉；
- 程序会自动忽略重复帧与无重叠帧，并在控制条提示状态；达到拼接上限会自动结束并生成已有结果；
- 如果长截图效果始终不理想，可以改用普通截图分段截取，再自行拼接。

## 十三、保存、复制与转发

点击「完成」后（以默认设置为例）：

- **复制到剪贴板**：截图会直接复制到剪贴板，打开微信聊天窗口按 `Ctrl+V` 就能发送；

点「保存」按钮（或 `Ctrl+S`）：

- 图片保存到设置里的「保存目录」；
- 默认目录是 **「图片」文件夹下的「微信截图助手」**（例如 `C:\Users\你的用户名\Pictures\微信截图助手\`）；

- 保存成功后编辑器自动关闭并提示保存位置。

点「转发到微信」：

- 图片自动复制到剪贴板；
- 程序会尝试把微信窗口切换到前台（如果微信正在运行）；
- 切换到微信后，选择好友聊天框按 `Ctrl+V` 即可发送；
- 如果没能自动切到微信，手动点一下微信窗口再粘贴即可。

> 微信「转发」功能无法也不需要模拟点击你的好友列表：本工具只负责把图准备好，发不发、发给谁由你在微信里决定。

## 十六、设置项、配置文件、绿色便携与卸载

### 设置窗口里的配置项

托盘右键 →「设置…」可以修改以下内容（首次运行会自动弹出）：

| 分区 | 配置项 |
| --- | --- |

| 底部按钮 | 恢复默认（API Key 会保留）、确定、取消 |

默认设置：完成时自动复制=开、自动保存=关、显示色值=开、显示尺寸=开、钉图置顶=开、显示用量=开、保存格式=PNG、翻译目标语言=中文。

- **配置文件位置**：
  - 正常情况下在 exe 同目录：`config.json`（首次保存设置时自动创建）；
  - 如果 exe 所在目录不可写（例如放在 `C:\Program Files`），自动改存到 `%APPDATA%\微信截图助手\config.json`；

- **换电脑 / 换 Windows 用户**：API Key 用当前 Windows 用户加密，无法跨电脑复制，需要重新填写；

  2. 打开设置取消勾选「开机自启」；

- **`config.example.json`** 是配置字段示例文件，仅用于说明各配置项，不包含任何真实 Key。普通用户不需要手动修改它。

## 十八、常见问题（FAQ）

**Q1：双击 exe 没反应 / 托盘里没有图标？**
A：程序启动后只驻留在托盘区（屏幕右下角，可能被折叠在「^」里）。点开小箭头看看是否有绿色图标；也可以双击托盘图标开始截图。若仍没有，检查是否被安全软件拦截。

**Q2：按 `Alt+A` 没有反应？**
A：常见原因有两种：

1. **热键被占用**：微信截图默认也是 `Alt+A`，可能已被微信、QQ、录屏或输入法软件占用。本工具启动时会自动尝试
   `Alt+Shift+A` → `Ctrl+Alt+A` → `Alt+Shift+S` → `Ctrl+Alt+S` 中第一个可用的组合，并弹出提示、把新热键写入配置。
   请看启动时的提示，或把鼠标悬停在托盘图标上（会显示「截图（当前热键）」），也可以在设置里自己改一个组合键。
   如果所有候选都被占用，程序会提示「全局热键 xxx 注册失败（可能被其他软件占用），请到设置中更换」。
2. **程序没在运行**：退出程序后热键会失效，确认托盘里有绿色图标。

如果提示「请先关闭设置窗口再截图」，把设置窗口关掉再按热键即可。

**Q3：提示 401（未授权）？**
A：API Key 不正确或已失效。重新到 DeepSeek 官网创建 Key，复制时注意**不要带空格和换行**，粘贴后点「测试连接」验证；确认 Key 属于当前登录的账号。

**Q4：提示 402（余额不足）？**
A：DeepSeek 账户余额不足，请到 platform.deepseek.com 充值后再试。

**Q5：提示 429（请求过多）？**
A：请求太频繁或触发限流，稍等十几秒再试；不要连续狂点 AI 按钮。

**Q6：AI 报其他错误 / 一直转圈？**
A：先检查网络是否正常、能否访问 api.deepseek.com；使用代理时确认代理可用；也可以在设置里适当调大「超时时间」。若提示图片过大，缩小框选区域后重试。把 `微信截图助手.log` 提供给开发者可帮助定位。

**Q7：截图是黑屏 / 截不到某些窗口？**
A：部分游戏、播放器使用了受保护的画面，任何截图工具都可能截不到。另外以管理员权限运行的程序（如某些系统工具）需要本工具也「以管理员身份运行」才能截取，可右键 exe → 属性 → 兼容性 → 勾选「以管理员身份运行此程序」。

**Q8：多显示器或高 DPI 缩放时位置不对？**
A：本工具支持多显示器和 125% / 150% 缩放。如果出现选区偏移、工具栏错位，请确认 Windows 显示缩放为推荐值，或把问题截图和 `微信截图助手.log` 发给开发者。

**Q9：杀毒软件 / 安全卫士报毒？**
A：绿色单文件未做商业签名，个别安全软件可能误报。请把 exe 加入信任/白名单，并从可信来源获取本工具；不要运行来路不明的同名文件。

**Q10：点「转发」没有自动切到微信？**
A：可能是微信最小化或被其他窗口阻挡。图片已经在剪贴板里，手动点开微信聊天窗口按 `Ctrl+V` 发送即可。

**Q11：开机自启不生效？**
A：某些安全软件会拦截开机启动项，请允许本工具；如果移动过程序文件夹，需要重新勾选一次「开机自启」。

**Q12：长截图拼接错位 / 有重复？**
A：目标页面滚动过快、含动画或悬浮元素时容易拼接不准。请放慢滚动速度，每滚一小段停一下再继续；纯色、空白或高度重复的页面建议缩小选区、分段多次截取；页面有弹窗/视频/悬浮广告时先关掉。程序会自动忽略重复帧和无重叠帧，如果仍错位，重试一次并放慢滚动，或改用多张普通截图。

**Q13：截图和配置保存在哪里？**
A：截图默认保存在 `图片\微信截图助手\`；配置和日志在 exe 同目录（或 `%APPDATA%\微信截图助手\`），详见第十六节。

**Q14：如何彻底退出 / 卸载？**
A：托盘右键 → 退出；再按第十六节关闭开机自启、删除文件夹即可。程序不会在系统里留下安装项。
