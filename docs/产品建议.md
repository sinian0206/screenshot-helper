# 产品建议

以下建议按对稳定性、使用效率和维护成本的影响排序，作为后续版本的评估输入。每项建议都可以独立实施，并应在实现前明确数据范围、失败行为和回归用例。

## 近期建议

1. **建立统一的文字选择入口**
   - 选择区域后显示识别状态、文本预览和复制结果。
   - 对低置信度文本提供“重试”和扩大选区提示。
   - 复制前保留换行规则设置，避免不同场景产生意外格式。

2. **补充钉图尺寸反馈**
   - 拖拽缩放时显示当前比例和像素尺寸。
   - 对过小窗口设置最小尺寸，对超过工作区的窗口自动限制范围。
   - 保存或复制时使用原始图片像素，不把窗口边框和控件写入图片。

3. **优化本地文字识别的可诊断性**
   - 在识别面板显示引擎、耗时、识别行数和失败原因。
   - 保留用户可见的原始文本，格式化输出作为单独操作。
   - 对小字号、低对比度、竖排文字和多栏布局建立固定样例集。

4. **改进编辑器状态提示**
   - 明确区分“选区未确认”“正在识别”“已复制”“已保存”和“操作失败”。
   - 长时间操作提供取消入口，取消后恢复到可编辑状态。
   - 所有快捷键在设置页和帮助页保持一致。

## 中期建议

1. **完善历史记录的可控性**
   - 默认关闭长期保存，只在用户完成或明确保存时归档。
   - 提供按日期、来源、是否含文字的筛选条件。
   - 清理操作显示将删除的数量和容量，并支持一次性清空。

2. **建立隐私处理审阅流程**
   - 将本地规则命中、可选联网补漏和人工补选分开显示。
   - 允许逐项取消、补选和撤销，并记录本次操作的范围。
   - 自定义敏感词和忽略词只在本机保存，导出配置时明确提示其内容。

3. **增加录制前检查**
   - 开始前检查输出目录、可用磁盘空间、音频设备和编码组件。
   - 提供短时测试录制，确认画面、声音和暂停恢复均可用。
   - 录制异常时保存可读的诊断摘要，避免写入截图内容或凭据。

4. **统一导入和输出模型**
   - 文件、拖放和剪贴板导入使用相同的尺寸限制、色彩处理和错误提示。
   - 拼图、长截图和钉图共用图片复制、保存和释放资源的实现。
   - 大图处理采用分块或延迟加载，避免一次操作占用过多内存。

## 长期建议

1. **建立可重复的质量基线**
   - 固定 OCR、隐私识别、DPI、混合显示器和录制场景的样例。
   - 每次发布记录构建版本、依赖校验值、测试范围和已知限制。
   - 将界面点击、键盘操作、取消、失败恢复和资源释放纳入自动化验收。

2. **完善可访问性**
   - 为所有图标按钮提供名称、快捷键和键盘焦点状态。
   - 支持系统字体大小和高对比度设置，避免仅通过颜色表示状态。
   - 对识别结果、审阅项和错误提示提供可复制文本。

3. **控制外部接口风险**
   - 联网功能只在用户主动触发并完成配置后执行。
   - 请求前显示发送范围，失败时不自动重试可能产生重复费用的请求。
   - 对凭据、请求日志和临时文件设置最小保存期限。

## 建议的验收标准

- 每个新功能至少包含一个成功路径、一个取消路径和一个失败恢复用例。
- 鼠标、键盘、DPI 100%/150%/200% 和多显示器坐标均有自动化覆盖。
- 大于常规桌面分辨率的图片、透明图片和超过存储上限的历史记录均有边界测试。
- 发布前使用干净目录启动主程序，验证依赖、配置、日志和卸载后的文件行为。
