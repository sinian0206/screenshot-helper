# 截图助手功能清单

版本：1.2.4。

| 功能 | 当前行为与边界 |
| --- | --- |
| 截图框选 | 拖拽时实时显示边框、遮罩、尺寸和窗口提示；可在设置中控制尺寸与色值显示 |
| 图片导入 | 支持文件选择、拖放、剪贴板粘贴，并进入同一标注编辑器 |
| 图形与文字 | 矩形、椭圆、箭头、画笔、文字、文字选择、序号、表情和马赛克；支持选择、移动、缩放、删除及撤销/重做 |
| 文字选择复制 | 在已选截图区域内拖动文字范围，使用本地 OCR 识别并复制到剪贴板 |
| 本地文字识别 | 优先使用系统离线识别能力，组件不可用时回退到随包运行时；不上传截图，支持长图切片 |
| OCR 格式 | 保留换行、合并段落、清理空格；按检测框输出制表符表格文本 |
| 原位翻译 | 使用本地识别行与编号关联；译文限制在原文框内，自适应字号和换行并保留完整文本对象 |
| 智能打码 | 本地规则先出结果，后台可选补漏；候选跨类别审阅、逐处取消、手动补选，整轮可撤销 |
| 自定义隐私规则 | 每行一个敏感词或忽略词，输入与规则文本有长度上限 |
| 截图历史 | 可关闭；保存完成或明确保存的截图；支持缩略图、文字/日期检索、收藏置顶、数量和容量修剪 |
| 保存与复制 | PNG/JPG、剪贴板、完成时可选自动复制或保存 |
| 钉图 | 鼠标拖动、右下角拖拽缩放、滚轮缩放、比例菜单、置顶、关闭按钮与右键操作 |
| 长截图 | 实时预览、捕获段与接缝检查、暂停/继续、撤回/恢复末段，错位时暂停 |
| 区域录制 | 框选后先选择本次音源与格式，再开始录制；支持暂停、系统声音、麦克风、混合音频和倒计时 |
| 拼图 | 多图横排或纵排、排序、间距、背景色、保存、复制或送回编辑器 |
| 延时与复用 | 托盘提供 3/5/10 秒延时截图，以及上次选区复用 |
| 界面控件 | 统一的浅色背景、文本层级、圆角控件、键盘焦点和高对比度状态 |
| 系统能力 | 托盘、自启、单实例命令转发、独立快捷键、DPAPI 凭据保护 |
| 多屏与 DPI | 物理像素映射、负坐标和按屏控件缩放；混合 DPI 仍需真实硬件验收 |
| 部署 | 主程序、x64 录制桥接 DLL、OCR 运行时与模型；无需独立 Python 或外部编码器 |

发布目录必须完整保留 `RecorderNative.dll` 与 `ocr` 文件夹。联网能力只在用户配置接口并主动触发相关操作时使用。
