# 微信截图助手（DeepSeek 版）功能清单

> 版本 1.0.0 · 对照对象：微信 PC 版（Windows 4.x）截图功能
>
> 下表逐项列出微信截图常用能力、本工具的实现情况、实现方式和差异，方便快速了解「哪些一样、哪些不同」。
> 「AI」标记的功能需要配置 DeepSeek API Key 并联网，会产生少量 API 费用。

## 一、基础绘制与编辑

| 功能 | 微信 PC 截图 | 本工具 | 实现方式与差异 |
| --- | --- | --- | --- |
| 矩形 | 支持 | ✅ 支持 | GDI+ 矢量绘制矩形框；颜色 8 种、线宽 4 档，右键「矩形」按钮调节 |
| 椭圆 | 支持 | ✅ 支持 | 同矩形，可画圆形/椭圆框 |
| 表情贴纸 | 支持（内置表情） | ✅ 支持 | 内置约 40 个常用彩色表情贴纸（Twemoji 素材）；点「表情」→ 选表情 → 在截图上点击放置 |
| 箭头 | 支持 | ✅ 支持 | 拖拽绘制带箭头的指示线；颜色、线宽可调 |
| 画笔 | 支持 | ✅ 支持 | 按住左键自由涂鸦；颜色、线宽可调 |
| 马赛克 | 支持 | ✅ 支持 | 按住左键涂抹打码；4 档笔刷大小（右键「马赛克」按钮调节） |
| 文字 | 支持 | ✅ 支持 | 点击输入文字，`Enter` 确认、`Esc` 取消；字号 5 档，输入时 `Ctrl+滚轮` 快捷调字号 |
| 序号标注 | 微信截图无此按钮 | ✅ 支持（增强） | **本工具增强功能**：工具栏「序号」按钮（快捷键 `N`），连续点击自动标注 1、2、3……；右键序号按钮可「重新开始编号」 |
| 颜色选择 | 支持多色 | ✅ 支持 8 色 | 红、橙、黄、绿、蓝、紫、黑、白，右键对应工具按钮选择 |

| 重做 | 微信无独立重做入口 | ✅ 支持 `Ctrl+Y` | 撤销后可恢复；`Ctrl+A` 可一键清空全部标注 |
| 标注可再编辑 | 微信可拖动调整已画内容 | ⚠️ 部分不同 | 本工具已画好的标注**不能再次选中拖动**，画错请用 `Ctrl+Z` 撤销后重画（保证实现简单、性能稳定） |

## 七、已知差异与使用限制（重要）

1. **已画好的标注不能二次拖动/修改**：画错请用 `Ctrl+Z` 撤销（或 `Ctrl+A` 清空）后重画；微信中可直接拖动已画内容。
2. **转发不是直接发送**：本工具只把图片复制到剪贴板并尝试切换到微信，发送对象和发送动作需要你在微信里完成。
3. **AI 功能依赖网络与 DeepSeek 账户**：断网、Key 无效、余额不足时 AI 不可用（普通截图功能不受影响）；AI 结果可能不准确，请人工核对。
4. **长截图依赖目标窗口可正常滚动**：滚动过快、页面含动画/悬浮元素或大片重复内容时可能拼接错位；程序会忽略重复帧和无重叠帧并提示状态，建议放慢滚动，纯色/重复内容页面建议缩小选区、分段截取。
5. **无法截取受保护画面**：部分游戏/播放器使用受保护渲染，任何截图工具都可能截成黑屏。
6. **未提供云同步/账号体系**：所有数据只保存在本机。
7. **程序未做商业代码签名**：极少数安全软件可能误报，请添加信任并从可信渠道获取。
