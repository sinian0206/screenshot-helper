# 截图助手 1.2.4 优化说明

本次版本集中处理界面一致性、交互验证和后续开源整理。

## 界面

- 主工具栏改为冷白浮层、深灰线稿图标和轻阴影。
- 选中工具使用浅蓝底，主完成操作使用系统蓝，不再使用大面积深色或多重强调色。
- 选区使用白色外轨、系统蓝内轨和圆形控制点；尺寸提示改为白色轻浮层。
- 设置、历史、文字结果和拼图窗口统一为冷白背景、柔和圆角与中性灰分割线。
- 移除切角、状态轨、装饰网格和强对比技术标签。

## 功能

- 录屏默认热键为 `Ctrl+Shift+P`。
- 移除工具栏中的额外转发入口。
- 支持图片导入、剪贴板导入、多图拼接、延时截图与上次选区复用。
- 增加可检索截图历史、收藏、条数与容量修剪。
- 增加自定义敏感词与忽略词。
- 增加录制准备、音源选择、倒计时与实时输入电平。
- 增加 OCR 格式切换和表格文本输出。
- 增加截图内文字选择、OCR 复制和钉图右下角拖拽缩放。
- 移除局部放大标注，减少低频工具和对象类型。
- 本地文字识别优先使用系统离线能力，并在不可用时回退到随包运行时。

## 修复

- 历史记录现在保存可检索的识别文本，并按收藏状态和日期排序。
- 历史容量限制会实际按文件大小修剪，不再只依赖记录条数。
- 更新旧版默认录制热键迁移，自定义热键和主动禁用保持不变。

## 验证

- 工具栏全部工具、动作、右键事件、禁用态和 100/150/200% 渲染。
- 浏览器界面展示器在桌面与 390×844 视口执行全部按钮、页签、开关、搜索和收藏交互。
- 七项功能专项回归、自检、冒烟、OCR、录制、长截图与打包回归。

详细结果见根目录 [VERIFICATION.md](../VERIFICATION.md)。
