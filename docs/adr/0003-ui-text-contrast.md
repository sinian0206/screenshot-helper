# ADR 0003：界面文案与截图内容配色分离

状态：已采用。日期：2026-10-19。版本：1.2.1。

## 背景

用户反馈所有界面文字偏淡。旧版白底副文字对比度 3.25:1、占位提示 2.31:1、白字绿按钮 2.38:1；禁用主按钮白字浅绿仅 1.34:1。UiTheme.Red/Green 还被标注默认颜色复用，不能全局改色以解决应用文案。

## 决策

- 保留原有截图标注色。固定 UI 文案集中使用 TextDark/TextGray/TextMuted，按钮与状态另用 ActionGreen/ActionRed；禁用态用深灰字和浅底区分可操作状态。
- 以普通文案 4.5:1 作为应用可控色对的最低目标，包括自绘禁用文案；它比标准对禁用控件的豁免要求更严格。测试读取真实控件属性和渲染文字区域，覆盖正常、悬停、按下、选中和禁用态。
- 操作系统原生标题栏、原生选中行由系统绘制，独立记录实际系统色，不宣称其符合应用自绘阈值或整个应用已通过完整 WCAG 认证。
- 选区尺寸与窗口名称使用不透明暗底白字，避免依赖原图颜色。用户输入栏保持深字，透明预览与导出保留所选颜色。
- 自动原位译文按 sRGB 相对亮度选择黑/白中对比度更高者，替代旧灰度阈值。复杂背景仍由现有背景覆盖策略处理。

## 验证

新增 contrast-regression 脚本记录实际色对和离屏渲染。另复用对象编辑、UI 逻辑、缩放布局及冒烟脚本检查文字大小变化后的可达性与布局。最终数据和范围见 VERIFICATION.md。

参考：[W3C Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum)。
