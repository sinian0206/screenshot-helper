# ADR 0004：菜单所有权、拖动绘制与录制准备

状态：已采用。日期：2026-10-20。版本：1.2.2。

## 背景

设置下拉菜单在关闭回调中同步释放，WinForms 消息过滤器随后仍访问菜单，造成 `ContextMenuStrip` 已释放异常。截图拖动每次重绘整屏遮罩，缩放钉图每次重做插值。录制在框选完成后立即启动，控制条占用较多画面。

## 决策

1. `SettingsComboBox` 持有并复用一个菜单，关闭仅改变可见状态；控件释放时统一释放菜单。托盘创建的模态设置窗口使用 `using`，确保 `ShowDialog` 返回后释放字体及子控件。回归通过真实消息循环和自有 HWND 的鼠标消息覆盖菜单过滤器路径。
2. 每个截图会话缓存静态暗化底图。选区移动、缩放和取色只使旧/新视觉范围失效；标注及输出仍使用原图。钉图在缩放尺寸改变时更新缓存，移动或重复重绘复用缓存；窗口关闭时释放缓存。用原版逐像素比较和离屏 p50/p95 衡量变化，不把离屏耗时等同于显示器刷新率。
3. 框选录制区域后进入独立准备窗。只有明确开始后才进入媒体会话、创建文件及打开音频设备。准备窗仅修改本次配置副本，取消返回重新框选。选择音频且格式为 AVI 时，显示提示并改为 MP4，保留音源选择。
4. 录制控制条约 360×44 DIP，保留时长、暂停/继续与停止；统计和文件名放入悬停提示。延续捕获排除、双缓冲及计时区域局部刷新，避免逐帧显隐。
5. 内置默认接口采用固定基础地址并拼接 `/chat/completions`。用户显式填写的基础路径保持原行为，不迁移服务或转移密钥。

## 验证与边界

设置、拖动性能和录制准备均有独立脚本。准备窗和控制条在 100/150/200% 缩放下检查布局、按钮状态与文字对比度。最终数据与运行限制见 `VERIFICATION.md`；离屏测试不替代真实混合 DPI 和长时间录制验收。
