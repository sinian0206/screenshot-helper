# 文字位置由本地 OCR 提供，联网服务只补充文字语义

旧流程依赖视觉模型返回文字与坐标，再按行顺序映射到本地估计位置，遇到多列、漏行和返回重排时会错配。本项目改为本地离线运行时检测文字与真实像素框，文本接口只翻译或分类带固定编号的识别行。随包运行时增加约 32 MiB，但让提取文字与规则打码可以离线工作，并使坐标来源可复现。

## 决策与约束

- `LocalOcr` 只返回识别文字、原图像素框及置信度。超长图采用重叠切片，并将框偏移回原图；UI 将这些框转换到选区坐标。
- 识别行编号在一次调用内稳定。翻译和语义分类必须按编号关联，不能按返回数组索引、原文数量或阅读顺序配对；缺失、重复或无效编号需报告失败，不能猜测补配。
- 译文只绘制在对应原文框内。容纳不下时使用裁剪与省略号，完整译文放在结果面板；不能扩框遮盖邻近内容。
- 本地 OCR 组件缺失或失败时明确报告，不静默切换到视觉模型上传截图。普通文字提取、翻译与文本语义补漏均不需要图片上传。
- `SemanticPrivacy` 默认开启；有 Key 时仅发送 OCR 文字，无 Key 时继续本地规则。`VisionPrivacy` 默认关闭，头像与二维码在该开关关闭时视为未检测；只有用户显式开启后才上传选区给支持图片的模型。
- 遮挡采用与原图像素独立的不透明图案。规则或模型命中只代表建议区域，结果必须保留给用户检查，不能把漏判风险转述为完整隐私保证。
- 原文、译文、完整 API 请求/响应和 Key 不写诊断日志；日志仅记录状态、数量、耗时和不含内容的错误信息。测试中显式生成的样本文件与文本须与生产日志区分。
- 1.1.1 起，本地规则结果先应用，再后台联网补漏。继续编辑、撤销、重选或关闭会取消该轮补漏；请求身份、选区及取消令牌共同限制迟到结果。整轮遮挡作为一个撤销项。
- 语义补漏不发送已命中本地规则的文字；视觉补漏上传前遮挡已确定的敏感文字。后台联网总预算不超过 20 秒，超时或失败保留已应用的本地结果。
- 桌面截图默认不做逐行方向翻转；图标过滤同时依赖置信度、同行正文和重复图标列的几何证据，不以短字符黑名单删除识别结果。
- OCR 输入走内存中的 PNG/base64 管道，不创建临时敏感截图。每次调用拥有可结束的子进程，取消、释放或 60 秒总超时均结束识别；同一实例不累积请求队列。

## 后果

发布物必须保留 `ocr` 目录、模型、字典、许可证与哈希清单，不能继续称为含模型的单文件程序。下载与构建复用 `C:\Dev`，构建采用 Visual Studio/MSBuild；引擎和模型升级需用中英、多列、小字、长图及生命周期回归证明兼容后再更换。

当前组件经过真实样本与生命周期测试，对外不承诺任意模型的准确率或兼容性。识别框为四点多边形的轴对齐边界，不提供逐字坐标；低清晰度、艺术字与任意旋转排版仍可能识别错误。外部接口兼容性需用有效凭据单独验证，本地模拟通过不等于真实服务通过。
