# ADR 0005：文字选择复制与钉图尺寸调整

## 状态

已接受。

## 背景

截图编辑器需要在不改变原图的前提下快速复制局部文字，钉图窗口也需要在查看期间调整显示尺寸。局部放大标注的使用频率较低，继续保留会增加工具栏、编辑对象和回归范围。

## 决策

- 新增“选择文字”工具。用户在已确认的截图选区内拖动范围，程序使用本地 OCR 识别该范围并复制结果；识别状态和失败原因通过状态提示反馈。
- 文字选择范围限制在当前截图选区内，输入图像按物理像素传给本地识别组件。
- 钉图增加右下角拖拽缩放手柄、滚轮缩放和比例菜单。窗口显示尺寸可以变化，复制和保存仍使用原始图片像素。
- 移除局部放大标注的工具入口、绘制实现和编辑副本支持，避免产生无法继续维护的对象类型。

## 结果

文字复制不依赖联网服务；识别失败时原图仍保留，用户可以扩大范围后重试。钉图缩放不会改变导出内容。工具栏状态、帮助文本和回归测试只保留当前功能集合。
